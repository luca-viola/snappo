# Snappo

**SN**apshot **APP**licati**O**n, a screenshot tool with barcode and OCR
capabilities. Grab the screen into the clipboard, then with one click replace it
with the text or barcode found in the image, ready to paste.

| Folder | Platform | Built with |
| --- | --- | --- |
| [`gnome-wayland/`](gnome-wayland/README.md) | GNOME Shell 51 | A GNOME Shell extension in JavaScript |
| [`macos/`](macos/README.md) | macOS | A menu bar app in Python, using rumps and py2app |

The original Python version, including its GTK interface for Linux, is on the
[`legacy`](https://github.com/luca-viola/snappo/tree/legacy) branch.
